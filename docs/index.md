# Cairn Software Guidebook

This documentation follows the [Software Guidebook](https://leanpub.com/documenting-software-architecture) approach by Simon Brown. The guidebook captures what you can't get from the code — context, architectural drivers, constraints, and decision rationale. It complements the [C4 model](https://c4model.com/) for visualising software architecture.
